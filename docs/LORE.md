# Bunny Meadow — Lore Ledger

Every named person, place, creature or object taken from folklore has an entry here before it may appear in [STORY.md](STORY.md).

Status values:

- **canon** — used as the source states
- **adapted** — source element with a stated change that does not contradict the source
- **invented** — ours. Must not contradict canon

## Source ledger

### Penghou, spirit of an old tree (彭侯)

| Field | Value |
