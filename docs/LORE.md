# Bunny Meadow — Lore Ledger

Every named person, place, creature or object taken from folklore has an entry here before it may appear in [STORY.md](STORY.md).

Status values:

- **canon** — used as the source states
- **adapted** — source element with a stated change that does not contradict the source
- **invented** — ours. Must not contradict canon

## Source ledger

### Chang'e (嫦娥)

| Field | Value |
| --- | --- |
| Status | canon |
| Primary tradition | Chinese. Earliest literary account in Huainanzi (淮南子), 2nd c. BCE |
| What the source says | Wife of the archer Hou Yi. Drank the immortality elixir obtained from Xiwangmu (Queen Mother of the West) and rose to the moon. Lives in loneliness on the lunar surface |
| Palace name | Guanghan Gong (廣寒宮, Palace of Vast Cold). Name attested in later literature including Journey to the West |
| Game use | Mentor voice through water reflections. Lonely emotional core. Asks Mei to stay in the finale |
| URLs | [Chang'e (Wikipedia)](https://en.wikipedia.org/wiki/Chang%27e), [International Dunhuang Programme](https://idp.bl.uk/discover/learning/chinese-astronomy/articles/astrology-and-myth/chang-e-or-the-archer-and-the-moon-goddess/), [Huainanzi](https://en.wikipedia.org/wiki/Huainanzi) |

### Jade Rabbit / Yutu (玉兔)

| Field | Value |
| --- | --- |
| Status | canon |
| Primary tradition | Chinese moon rabbit |
| What the source says | Companion of Chang'e. Pounds medicine or the elixir with mortar and pestle on the moon |
| Guard | Chinese tradition only. Do not import the Japanese mochi-pounding rabbit (Tsuki no Usagi) or mochi into this setting. Mooncakes are correct. Mochi is not |
| Game use | Comic NPC in the Moon Palace. Looks after Yue |
| URLs | [Moon rabbit (Wikipedia)](https://en.wikipedia.org/wiki/Moon_rabbit), [People's Daily, three faces of the Chinese rabbit](https://en.people.cn/n3/2023/0122/c90000-10199068.html) |

### Moon toad / chanchu (蟾蜍)

| Field | Value |
| --- | --- |
| Status | canon (optional background) |
| Primary tradition | Chinese. Han dynasty. Mawangdui funeral banners. Zhang Heng, Lingxian |
| What the source says | Oldest moon companion in Chinese visual tradition. Three-legged toad on the lunar disc. Later largely replaced in popular telling by the Jade Rabbit |
| Game use | Optional background NPC in Guanghan Palace. Never the antagonist |
| URLs | [Chang'e (Wikipedia)](https://en.wikipedia.org/wiki/Chang%27e), Dunhuang Programme article above |

### Tu'er Ye / Lord Rabbit (兔兒爺)

| Field | Value |
| --- | --- |
| Status | canon |
| Primary tradition | Beijing Mid-Autumn folk deity. Clay figurines attested since late Ming |
| What the source says | Auspicious rabbit figure, often armored, riding a tiger (also lion, deer, qilin). Said to be the Jade Rabbit sent by Chang'e to cure a plague in Beijing. Visited and honored at Mid-Autumn |
| Game use | World 3 ally. Lends his tiger for the ascent. Presence at the festival is itself canon |
| URLs | [Tu'er Ye (Wikipedia)](https://en.wikipedia.org/wiki/Tu%27er_Ye), [People's Daily](https://en.people.cn/n3/2023/0122/c90000-10199068.html) |

### Cranes as immortal messengers

| Field | Value |
| --- | --- |
| Status | canon (messenger role) / adapted (named Crane Envoy as story antagonist) |
| Primary tradition | Daoist and folk Chinese. Xiwangmu often rides a white crane. Immortals travel on cranes |
| What the source says | Cranes are mounts and messengers of immortals. Longevity and heavenly travel symbols |
| Adaptation | The Moon's messenger is a crane named the Crane Envoy. It mistakes glowing Yue for a fallen osmanthus blossom. Antagonist by misunderstanding, not malice |
| Guard | Owls are ill omens in traditional Chinese culture. They must not serve the Moon. Owls may appear as ordinary night enemies only |
| URLs | [Cranes in Chinese mythology](https://en.wikipedia.org/wiki/Cranes_in_Chinese_mythology), [Birds in Chinese symbolism (Chinasage)](https://www.chinasage.info/symbols/birds.htm) |

### Fox spirits / huli jing (狐狸精)

| Field | Value |
| --- | --- |
| Status | adapted |
| Primary tradition | Chinese fox-spirit folklore |
| What the source says | Foxes as shape-shifting tricksters. Surname/pun 胡 (Hu) / 狐 (fox) is traditional |
| Adaptation | Fox Hu stays a plain animal in a children's game. Keeps trickster flavor (steals carrots, blocks paths). Never truly dangerous. Named Hu, not Wu, to avoid clashing with Wu Gang |
| URLs | [Huli jing (Wikipedia)](https://en.wikipedia.org/wiki/Huli_jing) |

### Sasa Jataka (Jataka 316)

| Field | Value |
| --- | --- |
| Status | invented inspiration only (not Chinese canon) |
| Primary tradition | Indian Buddhist. Jataka tale of the hare in the moon |
| What the source says | A hare offers its body to a hungry brahmin (Sakka in disguise). Sakka paints the hare on the moon |
| Game use | Inspiration for the finale "gift" beat (mooncake and the promise to wave). Must be labeled as Indian Buddhist in credits or lore notes. Does not rewrite Chinese moon lore |
| URLs | [Sasa Jataka (Wikipedia)](https://en.wikipedia.org/wiki/%C5%9Aa%C5%9Ba_J%C4%81taka) |
