Status: planned. The rung between Osmanthus Peak and the Moon: an ocean of moonlit
cloud crossed on the Crane Envoy's wind. Hub: [../README.md](../README.md).

## Feel

A gap between earth and moon. Platforms are cloud shelves and wind gusts; below is
open void softened by more cloud so a fall reads as a drift, not a death. The glide
from Lantern Village matters most here. This is a transition rung: short, spectacular,
and light on enemies.

## Roster

## Endless status

Closed by default. The `osmanthus -> cloudsea` edge opens only when a run holds the
moon letter key ([../../items/catalog.md](../../items/catalog.md)); `cloudsea -> moon`
then leads to the terminal reward rung. Idea, not scheduled.

## Render notes

Deep-night sky over a pale cloud sea, star drift above. Night overlay on. Weather
preset: cloud wisps drifting across the foreground. Wind gusts are visible streaks
that double as the mover telegraph (see [../../rendering/animation.md](../../rendering/animation.md)).
